# 코잇다 화면 목록 v2

> 실제 구현된 Next.js App Router 페이지(`src/app/**/page.tsx`)를 기준으로 화면목록 v1을 갱신했다. **실제 라우트(URL)를 함께 표기**하고, 계획만 있고 미구현인 화면은 ⬜로 남겼다.
> 스택: Next.js 16 (App Router) · React 19 · TanStack Query 5 · RHF 7 + Zod 4 · Tailwind v4 · TipTap 3.
> 구현 상태: ✅ 구현 / 🟡 부분 / ⬜ 계획

## 0. v2 변경 요약

| 구분 | 화면 |
|---|---|
| **신규 구현** | 카카오 콜백·동의(`/auth/kakao/*`), 도안 문의(도안 상세 내 `InquirySection`), 판매자 문의함(`/seller/inquiries`), 구매 도안 상세·PDF 다운로드(`/library/[patternId]`), 게이지 계산(`/projects/[id]/gauge`), 둘러보기(`/explore`), 코잇기 피드(`/coitgi`) |

## 15. 핵심 흐름 (구현된 것)

### 흐름 1 — 도안 발견 → 니팅로그 시작 ✅
```
/ → /patterns → /patterns/[id]
      ├─ 구매 → /orders/[orderId] → /library → /library/[patternId] (PDF)
      └─ 니팅로그 만들기 → /projects/new → /projects/[id]
                                              └─ /projects/[id]/gauge (게이지 계산)
```

### 흐름 2 — 제작 기록 ✅
```
/projects/[id] → 오늘의 로그 작성(빠른/상세) → 상태·공개 재계산
```

### 흐름 3 — 리뷰·포인트 ✅
```
/patterns/[id] (보유+미작성) → /patterns/[id]/reviews/new → 포인트 적립 → /me/points
```

### 흐름 4 — 카카오 가입 ✅ (v2 신규)
```
/login → 카카오 → /auth/kakao/callback
   ├─ 기존 연결 → 로그인 완료
   └─ 신규 → /auth/kakao/consent (닉네임·약관 동의) → 로그인 완료
```

### 흐름 5 — 도안 문의 ✅ (v2 신규)
```
/patterns/[id] (문의 작성, 공개/비공개)
        ↓
판매자: /seller/inquiries (미답변 인박스) → 답변
```

## 16. 정합성 검증 (v2)

### v1 대비 해소
- ✅ 게이지 계산 화면(SCR-GAU-001) 요구사항 확보(GAUGE-001~016).
- ✅ 게이지 진입점 확정: **니팅로그 상세 → `/projects/[id]/gauge`**.
- ✅ 계산 결과 저장 위치 확정: `gauge_calculation`(니팅로그 귀속, 적용 1건).

### 남은 미구현(⬜) 집계
- 결제(PG)·환불·다운로드 재인증, 회원 탈퇴·도안 잠금, 도안 변경 이력·알림, AI 화면, 운영 콘솔(신고·금칙어·조치·예산), 공개 사용자 홈.
