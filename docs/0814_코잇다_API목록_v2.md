# 코잇다 API 목록 v2

> 실제 구현된 Spring 컨트롤러(24개 `@RestController`)를 기준으로 API목록 v2.3을 갱신했다. 계획만 있고 미구현인 엔드포인트는 ⬜로 표기해 유지한다.
> 구현 상태: ✅ 구현 / 🟡 부분 / ⬜ 계획

## 0. 공통 규칙 (구현 확인)

- **프리픽스**: 모든 API는 `/api/v1/**`. 프론트는 Next `rewrites`로 `/api/*` → Spring(`BACKEND_ORIGIN`, 기본 `localhost:8080`) 프록시.
- **인증**: 서버 세션(`HttpSessionSecurityContextRepository`, `SessionCreationPolicy.IF_REQUIRED`) + 세션 쿠키. 로그인 성공 시 SecurityContext를 세션에 저장(폼로그인 아님).
- **CSRF**: `CookieCsrfTokenRepository.withHttpOnlyFalse()`. 상태 변경 요청은 쿠키 `XSRF-TOKEN` → 헤더 `X-XSRF-TOKEN`. 프론트는 토큰 없으면 `GET /api/v1/csrf` 선호출.
- **권한**: 대부분 **URL 매처 기반**(`@PreAuthorize` 미사용). `/admin/**`=ROLE_ADMIN, `/seller/**`=ROLE_SELLER, 그 외 `authenticated()`, 화이트리스트만 permitAll.
  - ⚠️ `/seller-applications`(하이픈)는 `/seller/**` 매처에 안 걸려 **일반 인증**으로 통과.
- **오류**: `{ code, message, fieldErrors, traceId }`. 401=`UNAUTHENTICATED`, 403=`ACCESS_DENIED`.
- **비밀번호**: BCrypt. **역할 다중 보유** → 권한은 역할 목록 포함 여부로 판정.
