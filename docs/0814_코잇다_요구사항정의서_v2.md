# 코잇다 요구사항 정의서 v2

> 요구사항 정의서 v1.3 이후 **실제 구현·확정된 기능**을 반영한 개발 기준본이다. v1.3에서 유지되는 항목은 그대로 두고, 신설·수정분과 **구현 상태**를 표시했다.
> 구현 상태: ✅ 구현 / 🟡 부분 / ⬜ 계획(미구현)

## 0. v2 변경 요약

### 신설 (v1.3에 없던 사용자 확정 기능)

| 장 | ID | 내용 | 상태 |
|---|---|---|---|

| 1 | AUTH-006 개정 | 약관 동의를 **버전 문자열(1.0)로 저장**, 서비스·개인정보 필수 / 마케팅 선택 | ✅ |

**실제 계산 규칙(구현 확인)**
```
조정 콧수 = 도안 시작 콧수 × (내 게이지 코수 ÷ 도안 게이지 코수)   → 정수 반올림(HALF_UP)
예상 치수 = 도안 값 × (내 게이지 ÷ 도안 게이지)                    → 소수 1자리
필요 콧수 = 목표 치수 × 내 게이지 코수 ÷ 10   (폭 계열)          → 정수 반올림
필요 단수 = 목표 치수 × 내 게이지 단수 ÷ 10   (길이 계열: key에 'length')
추천 호수 = 내 게이지 코수 > 도안 → LARGER(+0.5) / 작으면 SMALLER(−0.5) / 같으면 SAME
경고 = 게이지 차이 ≥10%면 스와치 재확인 + 항상 '무늬 반복 단위 확인'
조정 요약 = |차이| ≥ 0.05 부위만  (chestCm=품, lengthCm=기장, sleeveLengthCm=소매, shoulderCm=어깨)
```
