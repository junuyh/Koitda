# 코잇다 요구사항 정의서 v1.3

> 요구사항 정의서 v1.2 이후 확정한 게이지 계산 기능과 부위별 목표 치수 조정을 반영한 개발 기준본이다. v1.2에서 유지되는 항목은 그대로 두고 변경·신설분만 표시했다.

## 0. v1.3 변경 요약

### 신설

| # | 내용 | 영향 |
|---|---|---|
| 1 | **13장 게이지 계산 신설** (GAUGE-001~015) | v1.2에 기능 요구사항이 아예 없던 영역 |
| 2 | **부위별 목표 치수 조정** — 사용자가 가슴둘레·총장·소매길이를 개별로 바꾸고 필요 콧수·단수를 계산 | GAUGE-007 |
| 3 | **계산 결과와 조정 내역을 니팅로그 공개 설정에 따라 함께 공개** | GAUGE-013·014 |
| 4 | 도안 사이즈·게이지 JSON 구조 확정과 권장 실측 키 | PATTERN-011 |

### 수정

| ID | 변경 |
|---|---|
| PATTERN-004 | 사이즈 정보에 **사이즈별 시작 콧수**를 필수로 추가 |
| SELLER-003 | 사이즈·실측을 자유 텍스트가 아닌 **행 단위 구조 입력**으로 변경 |
| AI-001 | 게이지 계산이 프로그램 담당임을 GAUGE-011로 구체화 |
| PROJECT-017 | 스냅샷 항목에 사이즈별 시작 콧수 명시 |

### 유지

v1.2의 리뷰(REVIEW-001~009), 포인트(POINT-001~006), 공개 설정 전파(POST-010·011, PROJECT-019), 상태 전이(PROJECT-020), 결제·정산(ORDER, SELLER-005), 데이터 보존(DATA-001~006)은 변경 없이 유지한다.

> PATTERN-011이 없으면 GAUGE-002의 자동 불러오기가 성립하지 않는다. 판매자마다 형식이 다르면 도안 정보를 계산에 쓸 수 없다.

## 13. 게이지 계산 ※ v1.3 신설

> 뜨개인은 도안대로 떠도 손 힘·실·바늘이 달라 결과 크기가 달라진다. 현재는 엑셀·AI·외부 계산기로 비례 계산을 하는데, 공통 한계는 **도안과 계산기가 분리되어 매번 숫자를 옮겨 적어야 한다**는 점이다. 코잇다는 도안이 니팅로그에 이미 연결되어 있으므로 이 단계를 없앤다.

### 13-1. 입력과 계산

| ID | 우선순위 | 요구사항 | 검수 기준 |
|---|---|---|---|
| GAUGE-001 | P1 | 니팅로그에서 게이지 계산을 실행한다. | 니팅로그 상세와 수정 화면에서 진입한다. 생성 화면에서는 제공하지 않는다. |
| GAUGE-002 | P1 | 구매·판매 도안 연결 시 도안 게이지·바늘 호수·사이즈별 시작 콧수·완성 실측을 자동으로 불러온다. | 사용자가 도안 정보를 다시 입력하지 않는다. PROJECT-017 스냅샷 값을 사용한다. |
| GAUGE-003 | P1 | 외부 도안은 도안 게이지·바늘 호수·시작 콧수·완성 실측을 사용자가 직접 입력한다. | 자동 불러오기 없이 계산이 가능하다. |

### 13-2. 1단계 — 게이지 보정

도안 치수를 **그대로** 내기 위한 계산이다.

| ID | 우선순위 | 요구사항 | 검수 기준 |
|---|---|---|---|
| GAUGE-006 | P1 | 내 게이지 기준으로 조정 콧수·단수를 계산한다. | `조정 콧수 = 도안 시작 콧수 × (내 게이지 코수 ÷ 도안 게이지 코수)`. 정수로 반올림한다. |
| GAUGE-007 | P1 | 도안 콧수를 그대로 떴을 때의 예상 완성 치수와 도안 대비 차이를 표시한다. | `예상 너비 = 도안 콧수 ÷ 내 게이지 코수 × 10`. 소수점 첫째 자리까지 표시한다. |
| GAUGE-008 | P1 | 게이지 차이에 따라 바늘 호수 방향과 추천 호수를 안내한다. | 내 게이지 코수가 크면 굵은 바늘, 작으면 얇은 바늘을 안내한다. 참고값임을 함께 표시하고 확정 지시로 제시하지 않는다. |
| GAUGE-009 | P1 | 계산식을 결과와 함께 표시한다. | 사용자가 검산할 수 있다. |

**바늘 추천 계산 (경험칙)**

```
추천 호수 = 도안 바늘 mm + (내 게이지 코수 − 도안 게이지 코수) × 0.5
```

### 13-3. 2단계 — 부위별 목표 치수 조정

도안 치수를 **일부러 바꾸려는** 경우다. 사용자가 결정하는 영역이며, 다음 사용자에게 가장 가치 있는 정보다.

| ID | 우선순위 | 요구사항 | 검수 기준 |
|---|---|---|---|
| GAUGE-010 | P1 | 사용자가 부위별로 목표 치수를 개별 조정한다. | 가슴둘레·총장·소매길이 등 도안이 제공한 실측 항목마다 목표값을 입력한다. 미입력 항목은 도안 값을 사용한다. |
| GAUGE-011 | P1 | 목표 치수에 필요한 콧수·단수를 계산한다. | `필요 콧수 = 목표 치수 × 내 게이지 코수 ÷ 10`. 시작 콧수 비례가 아닌 **치수 기준**으로 계산한다. |
| GAUGE-012 | P1 | 부위별 도안 값·목표값·차이·필요 콧수를 표 형태로 표시한다. | 조정한 부위가 구분되어 보인다. |

> **왜 치수 기준인가:** 톱다운 요크 스웨터는 시작 콧수가 목둘레다. 가슴둘레 106cm 도안의 시작 콧수 148코에 비율을 곱해도 품 조정이 나오지 않는다. 치수 기준으로 계산하면 부위와 무관하게 성립한다.

| GAUGE-017 | P1 | 계산 결과를 근거로 AI가 사이즈 조절 방법을 제안한다. | 사용자 확인 후 저장되며 계산 원본을 변경하지 않는다. AI 실패 시 계산 결과만으로 화면이 동작한다. |
| GAUGE-018 | P2 | 소매 코 줄임·코 줍기 등 부위별 세부 계산을 제공한다. | 초기 범위에서 제외한다. |

**GAUGE-014·015가 서비스 핵심과 이어진다.** 공개된 조정 내역은 다음 사용자에게 이렇게 읽힌다.

> 이 사람은 게이지가 24코라 도안보다 촘촘해서 콧수를 늘렸고, 품은 5cm 넓히고 소매는 3cm 줄였구나. 나도 품이 좁게 나오는 편이니 비슷하게 해야겠다.

기존 계산기는 결과를 저장하지 않아 이 정보가 매번 사라진다. 코잇다는 이를 누적해 다음 사용자의 판단 근거로 만든다.

### 13-5. 반올림과 예외

- 콧수·단수는 정수로 반올림한다.
- 무늬 반복 단위 자동 보정은 하지 않는다. 도안마다 달라 오히려 틀린 값이 나온다. 대신 "무늬 반복 단위를 확인하세요" 안내를 표시한다.
- 치수는 소수점 첫째 자리까지 표시한다.
- 도안 게이지나 시작 콧수가 없으면 계산을 제공하지 않고 입력 안내를 표시한다.
