## 프로젝트 개요

- **무엇인가** — 도안 탐색·구매 → 작품 계획 → 제작 기록 → 완성 공유를 한 흐름으로 잇는 뜨개 통합 플랫폼. *다른 사람의 실제 제작 정보(니팅로그)가 다음 사용자의 선택을 돕는 순환*이 핵심.
- **스택** — Java 21 · Spring Boot · PostgreSQL · Flyway / Next.js · TypeScript · Tailwind · TanStack Query · TipTap
- **로컬 실행·환경변수** — 루트 [`README.md`](../README.md) 참고

> 구현 진행에 따라 v2 문서의 구현 상태 표기(✅/🟡/⬜)를 갱신한다.
