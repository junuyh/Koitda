# 개발/데모 시드 스크립트

개발·시연용 더미 활동 데이터를 채우는 SQL 스크립트입니다. **개발/데모 전용 — 운영 DB 에서 실행하지 마세요.**

Flyway 마이그레이션이 아니라 수동 실행 스크립트입니다(빈 DB 재현은 마이그레이션 V1~가 담당하고, 여기서는 화면 시연용 활동 데이터만 얹습니다).

## demo_activity.sql

- **니팅로그 + 실·바늘·게이지**: 지정 도안들에 서로 다른 사용자의 제작 기록을 다수 생성해
  도안 상세의 **"니팅로그로 보는 실제 제작"** 집계(자주 쓴 실/바늘/게이지)를 채웁니다.
- **베스트셀러 구매**: 일부 도안의 구매수를 올려 홈 **베스트셀러** 순위를 다양하게 만듭니다.

도안은 **제목 기준**으로 찾으므로, 해당 제목의 승인된 도안이 있을 때만 시드합니다.
이미 충분히 채워진 도안(로그 5+/구매 목표치 도달)은 건너뛰어 **재실행해도 크게 중복되지 않습니다.**

### 실행

로컬 dev DB(PostgreSQL, 예: Docker 컨테이너)에 적용:

```bash
# 컨테이너 id 확인 후
docker exec -i <postgres-container> psql -U koitda -d koitda < scripts/dev-seed/demo_activity.sql
```

시드 사용자 닉네임은 `데모제작러_*`, `데모구매러_*` 접두사라 나중에 식별·정리하기 쉽습니다.
